SYSTEM ZERO Lite — Personal Progress Tracker

Project Overview

SYSTEM ZERO Lite is a simple C-language console application that helps users track daily missions, earn experience points (XP), and monitor their progress.

Features

- View predefined missions
- Mark missions as completed
- Earn XP for completed missions
- View completed mission count
- Calculate progress percentage
- Display total XP

Technology Used

- Programming Language: C
- Development Environment: Online C Compiler (initial prototype)
- Version Control: Git and GitHub

How to Run

1. Open "main.c" in a C compiler.
2. Compile and run the program.
3. Select an option from the menu.

Project Status

Micro Project prototype: basic mission tracking and progress calculation implemented.

Future Enhancements

- Save progress using file handling
- Add new missions
- Search missions
- Add XP levels and statistics
- Demonstrate Git branching and pull requests

Author
